# ARC Datasets

These JSON datasets were provided with the Georgia Tech KBAI
ARC student starter and are included for experimental reproducibility.

- ARC-AGI-1: Public ARC-AGI-1 dataset.
- ARC-AGI-2: Public ARC-AGI-2 dataset.
- problems: Starter submission dataset directory, initially using ARC-AGI-1.

The datasets are not original contributions to this repository.
